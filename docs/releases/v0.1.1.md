### 全屏只显示监控画面

- 实时预览和录像回放进入全屏后，隐藏侧栏、工具栏、画面标题、状态、按钮、录像列表和时间轴。
- 移除所有外边距、画面间距和边框，各路视频拉伸铺满自己的分屏区域，保留完整监控内容；比例不一致时画面会有变形。
- F11 或 Esc 退出后恢复控件、间距和原始视频比例，原本最大化的窗口仍恢复为最大化。
- 轮巡生成的新画面自动沿用全屏样式；切换全屏不重建播放器或重新连接码流。

本地已验证四路合成视频全屏播放、铺满比例、退出后继续播放与比例恢复；布局检查覆盖四分屏、单路放大、轮巡换页及录像回放。原有 28 项自动测试通过。

完整解压后运行应用。Windows/macOS 包含 VLC 与 FFmpeg，无需 Python；Linux 需要系统 VLC 和 X11/XWayland。应用未使用发布者证书签名或完成 macOS 公证。

各包附带 SHA-256 和构建记录。Windows/Linux 的 Actions 执行打包后原生播放检查；macOS 云端仍仅检查组件加载和 FFmpeg 解码，真实 Mac 的原生播放已另行验证。

原有设备和网络限制仍适用：部分通道可能停顿重连，测试 NVR 的第二路并发回放返回 RTSP 453。详情见 README 和 v0.1.0 发布说明。密码文件与私有录像不包含在发布包中。
