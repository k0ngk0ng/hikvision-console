首个桌面版本：直连海康 NVR，支持动态通道发现、多画面实时预览、主子码流切换、录像搜索与回放、截图、MP4 导出、断线重连，以及设备支持的事件、存储和云台功能。NVR 和树莓派无需部署软件。

### 下载与启动

从下方 Assets 下载对应系统的文件，完整解压后运行：

| 系统 | 文件 | 启动方式 |
| --- | --- | --- |
| Windows x64 | `HikvisionConsole-0.1.0-Windows-amd64.zip` | 打开 `HikvisionConsole.exe` |
| macOS Apple Silicon | `HikvisionConsole-0.1.0-Darwin-arm64.zip` | 打开 `Hikvision Console.app` |
| Linux x64 | `HikvisionConsole-0.1.0-Linux-x86_64.tar.gz` | 执行 `./HikvisionConsole/HikvisionConsole` |

Windows/macOS 已包含 VLC 和 FFmpeg，无需安装 Python。Linux 需要系统 VLC 和 X11/XWayland；Ubuntu 可执行 `sudo apt install vlc libvlc5 libxcb-cursor0 libxkbcommon-x11-0`。Intel Mac 不适用 ARM64 包，需从源码构建。

首次启动填写 NVR 地址、账号、密码。密码仅保留在当前会话，不写入设置或安装包。`.nvrpass` 不包含在源码和发布资产中。

每个压缩包附有 `.sha256` 校验文件和 `.json` 构建记录。应用尚未使用发布者证书签名或完成 macOS 公证；系统可能提示未知开发者。

### 验证与已知限制

- 三平台包由 GitHub Actions 构建，通过 28 项行为测试和代码检查后发布；Windows/Linux 另执行打包后原生播放测试。
- macOS 云端 runner 无法创建 VLC 所需的 OpenGL 上下文，云端执行组件加载和 FFmpeg 解码检查，JSON 明确标记此范围。同版本应用及此前 Actions 生成的 macOS 包已在真实 Mac 验证原生播放、暂停、倍速和截图。
- 真实 NVR 的 10 分钟六路预览，以及单路回放、暂停、2× 请求、录像导出流程已通过。部分通道仍明显停顿并重连，尚不能承诺长期稳定流畅。
- 本次测试的 NVR 拒绝第二路并发回放（RTSP 453），建议单路回放。倍速和云台取决于设备能力；此版本没有对讲。
- Windows 测试机尚未连通真实 NVR，其播放验证使用合成视频。

完整操作说明和第三方组件说明见仓库的 README.md、THIRD_PARTY.md。
