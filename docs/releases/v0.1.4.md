### 实时预览与回放操控

- 修复全屏切换短暂隐藏页面时停止全部预览的问题。预览增加页面级巡检，意外停止后自动恢复；播放时钟冻结也会触发重连。
- 回放画面占满内容区宽度，移除分段列表。检索后自动开始播放，点击底部时间轴定位，自动选择录像、跳过空缺并跨段续播。
- 增加快进按钮和最高 16× 播放。实际倍速由设备决定，拒绝请求时显示设备错误。
- 数字放大后，单击画面调整放大中心。支持最高 4× 数字放大。
- 全屏回放时单击视频显示或隐藏底部控制与时间轴；空闲后自动收起，操作控制区时保持显示。
- 新增本地人脸抽样定位。点击「找人脸」后加速回放，发现疑似正面人脸时暂停并标记时间轴。设备拒绝高倍速时逐级降速；可随时停止。检测在本机运行，临时截图检测后删除，不识别身份；可能漏检或误检，不能替代完整录像检索。

### 下载与限制

完整解压后运行。Windows x64 与 macOS Apple Silicon 包含 VLC、FFmpeg 和人脸检测组件；Linux x64 需要系统 VLC 和 X11/XWayland。应用未使用发布者证书签名或完成 macOS 公证。每个平台提供 SHA-256 校验和 JSON 构建记录。

旧 NVR 的带宽、解码和会话数量限制仍然适用。本次真实设备的 16× 请求返回 RTSP 453，不能声称该型号已通过 16× 实测。

验证方法与产物说明见 [回放与预览恢复验证](../playback-validation.md)。本地行为回归、合成视频原生 E2E、真实设备工作流，以及各平台打包检查分别记录，不将组件检查视为原生画面验证。
