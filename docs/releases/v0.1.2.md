### Windows 体验与双击预览

- 修复 Windows 启动实时预览、录像回放或自动重连时，FFmpeg 子进程弹出命令行窗口的问题。
- 修复 Windows 运行后任务栏图标变成空白图标：应用使用随包附带的多尺寸 ICO，设置稳定的任务栏应用标识。
- 实时预览可直接双击视频进入单路高清，再次双击返回原来的分屏页。全屏下同样有效，并保持无按钮、无边距的画面布局。

Windows runner 已验证实际拉流子进程不创建控制台；打包程序的原生播放检查新增窗口图标、任务栏标识和真实鼠标双击检查。双击切换、返回原分页及主子码流选择也已通过行为测试。macOS 本地原生播放检查通过；macOS 云端仍执行组件加载与解码检查，Linux 执行打包后原生播放检查。
