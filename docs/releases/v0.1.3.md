### 界面、全屏双击与软件更新

- 修复 Windows 内嵌视频占用原生鼠标事件时，全屏双击不进入单路预览的问题。再次双击返回原分屏页，保持全屏。
- macOS 使用应用内 Cocoa 事件处理原生视频上的双击及全屏快捷键。
- Windows 包内的 FFmpeg 使用 GUI 子系统，并为子进程设置隐藏启动选项，覆盖预览、回放和导出时的命令行窗口问题。
- 标题栏和左侧品牌下方显示 `v0.1.3`，软件更新窗口也显示当前版本。
- 调整普通窗口的画面布局，将码率和帧率移至状态行，保证静音、截图和缩放控件的完整高度。小窗口空间不足时可滚动，全屏仍只显示无间距视频。
- 极小窗口下左侧导航也可滚动，避免按钮文字被压缩裁切。
- 开始／停止预览立即显示操作状态，短暂禁用以避免重复点击；常用按钮增加按下、选中和禁用效果。
- 新增 GitHub 最新稳定版检查、下载进度、取消下载、SHA-256 校验、安装并重启。默认启动时及每 6 小时检查，允许关闭自动检查；下载和安装需点击触发。

### 升级

**v0.1.2 及更早版本请先手动下载安装此版本，后续即可使用软件内更新。**

| 系统 | 文件 |
| --- | --- |
| Windows x64 | `HikvisionConsole-0.1.3-Windows-amd64.zip` |
| macOS Apple Silicon | `HikvisionConsole-0.1.3-Darwin-arm64.zip` |
| Linux x64 | `HikvisionConsole-0.1.3-Linux-x86_64.tar.gz` |

完整解压后运行。Windows/macOS 包含 VLC 与 FFmpeg，无需 Python；Linux 需要系统 VLC 和 X11/XWayland。应用未使用发布者证书签名或完成 macOS 公证。每个平台附有 SHA-256 校验文件和 JSON 构建记录。

自动更新要求安装目录可写，保留连接设置，密码需重新输入。旧版保留在安装目录旁的 `*.previous-<标识>`；替换失败时恢复旧目录，不包含启动失败后的自动回退。录像导出期间暂不安装更新。

设备和网络限制同前版：部分通道可能停顿重连，测试 NVR 的第二路并发回放返回 RTSP 453。密码文件与私有录像不包含在发布包中。

### 验证范围

- 本地 Mac 的打包应用使用合成视频实际播放，鼠标双击完成全屏多画面 → 单路 → 多画面，Esc 返回普通窗口；检查了控件完整显示、声音按钮状态、截图保存及更新窗口版本号。另已验证更新包下载校验、替换和重启。
- GitHub Windows runner 运行实际打包 EXE，在 125% 缩放下用系统鼠标输入验证双击往返，检查 FFmpeg 子进程无控制台、窗口图标和任务栏标识；不代表已在用户的 Windows 机器或其 NVR 网络上验证。
- Linux runner 验证打包程序的原生播放。macOS runner 仅验证打包组件，原生画面交互由本地 Mac 验证。
